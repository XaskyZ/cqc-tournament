Откройте профиль в игре

  1. Запустите Mobile Legends и нажмите на свой аватар.
  2. Скопируйте числовой ID игрока.
  3. Число в скобках рядом — это Server ID.

Проверьте перед сохранением

Пара Game ID + Server ID должна совпадать с данными, которые капитан указал в составе.

После привязки к месту в команде менять игровой аккаунт нельзя. Если в составе ошибка, обратитесь к капитану или организатору.

Поиск ника помогает проверить данные профиля, но сам по себе не подтверждает владение игровым аккаунтом.
