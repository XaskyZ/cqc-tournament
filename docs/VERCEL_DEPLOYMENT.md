## Размещение

Отдельный проект Vercel `cqc-tournament` в `araki-s-team`, Python 3.12 / Django. Отдельный бесплатный Supabase `cqc-tournament-preview` в `eu-central-1`. Другие проекты Supabase и `cqcstore` не изменялись.

База подключена через transaction pooler с TLS; prepared statements, server-side cursors и постоянные Django-соединения отключены. Роль `cqc_tournament_app` использует собственную схему `tournament`, закрытую для Supabase `anon` и `authenticated`. Браузер обращается только к Django, ключей БД в клиентском коде нет.

Перенесены только настройки демонстрационного турнира. Локальные игроки, команды, платежи, сессии и пароли не копировались. Создан новый организатор: доступ хранится в `.local/cloud-admin-access.txt`.

Переменные Vercel помечены sensitive. Деплой собран из разрешённых исходников в отдельной папке: `.env`, `.local`, базы, резервные копии и артефакты не загружаются. Дополнительная защита — `.vercelignore`.

## Telegram

Включён HTTPS webhook `/telegram/webhook/`, секретный заголовок, одна одновременная доставка, очередь Telegram сохранена. Локальный polling остановлен. Маркер `.local/cloud-webhook.json` заставляет `start.ps1` пропускать локальный бот. Telegram-вход следует начинать на публичном адресе.

Не запускайте polling одновременно с webhook. Возврат к локальному режиму требует отдельного переключения и проверки очереди; удаление маркера само по себе не переносит бот. [Подробности](TELEGRAM_WEBHOOK.md).

## Обновление и ограничения

Исходники автоматически не публикуются: нужен новый Vercel deployment. Миграции выполняются отдельно с проверкой `DATABASE_URL`, никогда из HTTP-обработчика. Локальную SQLite в Vercel не загружать.

До реального приёма взносов нужны утверждённые условия, банковский тест, отдельный обработчик финансовой очереди, мониторинг и резервные копии PostgreSQL. `backup_database` поддерживает только локальную SQLite. Расписание очистки сессий, истёкших лимитов и старых webhook receipts пока не установлено. Бесплатные сервисы ограничивают ресурсы; неактивная база может приостанавливаться.

Источники: [Django на Vercel](https://vercel.com/docs/frameworks/full-stack/django), [подключения Supabase](https://supabase.com/docs/guides/database/connecting-to-postgres).
