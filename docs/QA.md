## Разделение работы

- Основная реализация: интеграция сайта, права HTTP-маршрутов, формы, админ-панель, запуск и документация.
- Доменный агент: база, взносы, составы, двойная сетка; затем независимый аудит веб-прав и Telegram-входа.
- Telegram-агент: очередь кассира, решения, вход через Telegram; затем независимые случайные симуляции сетки.
- Frontend-агент: адаптивный интерфейс, реальные браузерные сценарии и визуальная проверка.
- Отдельная исследовательская задача доменного агента: первичные документы API игровых ников, отключённый адаптер и тесты контракта.

Одновременно использовалось до трёх рабочих агентов и основной координатор; реализация и независимые проверки проходили несколькими этапами.

## Браузер

В Chrome проверены ширины 390 и 1440 пикселей, отсутствие горизонтального переполнения и ошибок JavaScript. Первый изолированный сценарий: регистрация капитана → состав 5 + 1 → личная страница → заявка на проверку → отклонение неполной формы проверки → подтверждение организатором → автоматическое обновление страницы участника. После добавления Telegram прошёл отдельный сценарий: начало входа → ожидание → имитированный ответ бота → автоматическое обновление страницы → явное подтверждение профиля → игровой профиль → совпадение ID с составом → подтверждение участия → доступ к заявке на оплату и блокировка изменения игрового профиля. Имитация использует только демонстрационную базу, без отправки сообщений реальным пользователям.

Снимки находятся в `artifacts/qa/`. На демонстрационных снимках могут присутствовать явно тестовые команды, пользователи и банковские номера. Их нет в рабочей базе.
