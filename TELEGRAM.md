# Бот турнира CQC

Бот: https://t.me/cqc_tournamentbot

Бот подключён к базе сайта. Единственный кассир — Telegram ID `855341070`. Команды `/start`, `/id`, `/pending` доступны; финансовые сведения и решения выдаются только кассиру в личном чате. Другие пользователи не получают права через `/start`.

## Вход участников

Кнопка на сайте создаёт одноразовый запрос на 10 минут. Ссылка открывает бота с непрозрачным параметром; шестизначный код виден отдельно только в исходном браузере. Пользователь отвечает кодом на запрос бота, подтверждает действие кнопкой, возвращается в браузер и подтверждает показанный Telegram-профиль. `/start` без такой ссылки только показывает ID/роль и не привязывает аккаунты.

После пяти неверных кодов запрос закрывается. Повторный вход по использованному запросу, завершение из другого браузера, подмена Telegram ID и автоматическое объединение разных аккаунтов запрещены. Существующий пользователь привязывает Telegram только из своей авторизованной сессии. Новые аккаунты создаются без пароля и без прав администратора. Game ID/Server ID вводятся отдельно на сайте; вход в Telegram не доказывает владение игровым аккаунтом.

## Настройки

Токен хранится только в `.env`, который исключён из Git. Образец без токена — `.env.example`. Несмотря на название, `TELEGRAM_CASHIER_IDS` принимает ровно один явно подтверждённый положительный числовой ID: по решению организатора кассир единственный. Передача токена и нажатие пользователем «Начать» сами по себе не включают права кассира.

## Запуск

Требуется окружение из `requirements.txt` и выполненные миграции Django.

```powershell
.\.venv\Scripts\python.exe scripts/telegram_bot.py inspect
.\.venv\Scripts\python.exe manage.py run_bot
```

Запускайте только один экземпляр получателя обновлений. Команда отказывается стартовать при установленном webhook. Позиция чтения обновлений и диалоги проверок сохраняются в базе. После перезагрузки компьютера запустите `start.ps1`; системный автозапуск ещё не настроен. Старый режим `scripts/telegram_bot.py run` использовался только для первичной привязки и больше не запускается.

Профиль и команды обновляются командой `python scripts/telegram_bot.py configure`. Аватарка устанавливается командой `python scripts/telegram_bot.py set-photo --photo artifacts/cqc-bot-avatar.jpg`.

После «Я оплатил» создаётся запись очереди. Бот отправляет карточку кассиру с кодом взноса, командой, игроком и суммой. Для подтверждения кассир сверяет поступление в Kaspi, вводит номер реальной банковской операции ответом на запрос бота и нажимает финальную кнопку сверки. Для отказа указывает причину. Номер CQC не принимается как банковский номер. Переход статуса, журнал и закрытие диалога атомарны; старые/повторные кнопки не подтверждают новую заявку. Страницы сайта проверяют изменение статуса каждые 15 секунд.

Очередь доставляется с повторами: при редком сетевом сбое возможна повторная карточка, но повторный зачёт запрещён. Время последнего решения и ID кассира сохраняются. Возвраты выполняются отдельно в Kaspi Pay и не автоматизированы.
